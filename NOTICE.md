# Attribution and scope

This is a community-maintained GitHub fork of
[MotionSites Web Builder](https://github.com/Motionsites-AI/claude-skill),
maintained by su-record. It is not an official MotionSites release.

The source revision is recorded in the skill's `references/upstream.json`.
The design references and original screenshot helper are © 2026 MotionSites
and released under MIT. This adaptation preserves that copyright and license.

The upstream `examples/`, `media/`, preview images, and linked media collection
are excluded from the current distributed skill and release ZIP. The original
files remain in upstream Git history under their original terms, preserved in
[UPSTREAM_LICENSE](UPSTREAM_LICENSE).
The optional downloader retrieves them directly from upstream for local use.

Changes include shared Claude Code/Codex instructions, portable script paths,
Codex UI metadata, Claude Code plugin packaging, corrected reference paths,
an optional resource cache, and screenshot/report validation. The original
mandatory advertising instructions are removed.
